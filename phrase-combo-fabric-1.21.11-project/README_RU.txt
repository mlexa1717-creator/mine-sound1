PHRASE COMBO — экспериментальный исходный проект Fabric 1.21.11

ВАЖНО: готового JAR в архиве нет. Проект не компилировался и не тестировался
в Minecraft. Совместимость требует проверки. Не переименовывайте ZIP в JAR.

Звуки: 1 Нормально; 2 Бля, не; 3 Еще посидим.
Нарезка предварительная, по паузам исходного MP3.
Сброс >= 1.1 секунды; после третьего звука снова первый.
Новая фраза прерывает предыдущую, чтобы речь не накладывалась.
Урон и скорость атаки код не меняет. Fabric API не требуется.

СБОРКА НА GITHUB
1. Создайте пустой репозиторий (лучше приватный из-за аудио).
2. Распакуйте архив и загрузите его СОДЕРЖИМОЕ в корень репозитория.
   Включите скрытую папку .github с workflows/build.yml.
3. В Actions откройте Build mod, дождитесь успешного запуска.
4. Скачайте artifact phrase-combo-1.21.11 и распакуйте.
5. Полученный phrase-combo-1.0.0.jar положите в mods вашего профиля
   Minecraft Java 1.21.11 с Fabric Loader >= 0.18.1.
Локальная сборка: JDK 21, Gradle 9.2.1, команда gradle build.
Готовый JAR появится в build/libs (не используйте sources.jar).

ОГРАНИЧЕНИЯ ЭТОГО ПРОТОТИПА
Это клиентская замена по звукам атаки рядом с координатами игрока,
а не точное подтверждение нанесенного урона сервером.
strong/weak/crit/sweep переключают серию, nodamage/knockback — нет.
Чужой удар в непосредственной близости может вызвать ложное срабатывание.
При задержках сети или нестандартных серверных звуках возможны пропуски.
Дубли звуков в пределах 50 мс подавляются; это тоже эвристика.
Для строгого подтверждения каждого вашего успешного попадания потребуется
другая реализация с серверным подтверждением. Этот проект такой гарантии не дает.

ПРОВЕРКА ПОСЛЕ СБОРКИ
Проверьте запуск игры, обычные/критические/размашистые атаки, промахи,
паузы 1.0 и 1.2 секунды, переподключение и бой рядом с другим игроком.
Если сборка не удалась, сохраните полный лог Actions для исправления.
